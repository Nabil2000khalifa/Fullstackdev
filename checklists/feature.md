# Feature delivery checklist

- [ ] Request, non-goals, roles, acceptance criteria, and failure states defined
- [ ] Existing patterns, dependencies, API/data flow, and technical decisions inspected
- [ ] Authorization and validation rules defined at the server boundary
- [ ] UI loading, empty, error, success, disabled, and accessible states covered
- [ ] Focused tests added for new behavior and edge cases
- [ ] Direct callers and integrations regression-tested
- [ ] Documentation, project state, task tracker, and handoff updated
