# Reusable audit checklist

- [ ] Repository, stack, scripts, Git state, and project memory inspected
- [ ] Acceptance criteria and affected modules identified
- [ ] Responsive and overflow behavior checked at representative viewports
- [ ] Visual tokens, typography, focus, semantics, and contrast checked
- [ ] Every in-scope interaction tested in success and failure states
- [ ] API contracts, authorization, validation, calculations, and persistence checked
- [ ] Security threats and dependency/configuration risks reviewed
- [ ] Relevant tests, type checks, lint, build, and regression checks executed
- [ ] Five quality levels scored with evidence
- [ ] Memory files and handoff updated
- [ ] Remaining risks and blocked checks reported
