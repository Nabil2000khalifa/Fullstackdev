# Release readiness checklist

- [ ] Version, branch, environment, and working tree recorded
- [ ] Build, type, lint, unit, integration, and end-to-end checks run as applicable
- [ ] Critical user journeys smoke-tested
- [ ] Security findings triaged; no unresolved critical issue
- [ ] Database migrations reviewed, ordered, and recoverable
- [ ] Configuration and secrets supplied through approved mechanisms
- [ ] Logging, metrics, health checks, alerts, and redaction reviewed
- [ ] Performance and capacity risks assessed
- [ ] Backup and restore or recovery procedure documented
- [ ] Rollback trigger and procedure documented
- [ ] Known issues, blocked checks, and residual risks reported
